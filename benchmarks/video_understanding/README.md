# Story 030 Synthetic Video Benchmark Dataset

These clips are locally generated previz-style fixtures used to calibrate the
video-understanding benchmark without licensing ambiguity. Each clip directory contains
`clip.mp4`, `target.md`, `target.json`, `meta.json`, and sampled analysis frames.

Anchor subset for the first pilot run: dialogue_confession_push_in, alarm_chase_whip_pan, quiet_bedside_vigil, prop_swap_continuity_break, neon_crosswalk_reveal, muzak_aftermath_tableau
