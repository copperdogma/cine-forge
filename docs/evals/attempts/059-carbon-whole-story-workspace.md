## Source and consumer gates

outer string. The response schema enforced the outer envelope. CineForge's
original Python host schemas and reference checks applied after lossless JSON
decoding. Preflight round-tripped the authored exemplar through the real
ArtifactStore and OperatorConsole with 149 equal groups and four scenes.
Fresh native counts including the rendered outer schema were 6,829, 6,753 and
6,744. The exemplar's wire representation counted at 19,190 Carbon input-text
tokens, compared with the earlier Fable counter's 37,220. The example was only
sent to the free token counter.

All three candidate canonical texts matched every original character except
the final newline, which every supplied source included. First-hop read-only
stored retrievals on Open Frequency and Last Ferry confirmed exact original
prompt bytes including that LF. **Original host acceptance was 0/3.**
A separately labeled one-byte derivative restored only that known LF.
Open Frequency loaded 117 groups; Matinee Echo loaded 90. Every payload was
read through the real OperatorConsole, all health labels were valid and all
four scenes were searchable. No derivative replaces an original scored answer.
Last Ferry still fails two gap references. Its Tom and white-bandage timelines
supply explanatory prose where the host requires scene IDs. The rendered
semantic schema specifies strings, while the scene-ID convention is documented
in a Python comment and used by the maintained builder. This is a genuine
integration failure with an underspecified prompt projection.

Blind complete-source reviewers inspected original answer objects and full
consumer payloads independently, including source spans, actions, role identity,
directed handoffs, graph endpoints and continuity. Source checklists were
frozen before those reviews. In the initial Open Frequency control packet,
a producer identifier leaked in intermediate discovery metadata. A new
independent reviewer re-read all 82 groups with that field removed and reached
the same six stale morning states and 17 unresolved endpoints. Model policy
fields common to all arms were preserved. This did not require a new inference.
The whiteboard truth is an ambiguity: Carbon's prose acknowledges two boards
could exist, but its typed timeline assigns the same entity a confident contents
change across the two locations. The source never confirms a board moved.
Narrative location mentions are credited separately from usable structured
accounting. Additional linked reviewer files retain the full judgments.
