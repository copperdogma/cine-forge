# Carbon ordered-frame contract, November 10, 2026

The maintained Google ordered-frame adapter already renders the neutral text and
five indexed JPEGs through GenerateContent and validates Gemini usage, serving
identity and terminal STOP. The current native model supports images and
structured output. We reused the maintained responseSchema projection with all
13 fields required and locally validate the exact key set and original
VideoAnalysisPrediction. The native request omits sampling, explicit cache and
tools. The stateless, serial subject route has one 32,768-token foreground
allowance including thinking. No continuation is authorized for these frames.
[Model](https://ai.google.dev/gemini-api/docs/models/gemini-4-carbon),
[migration](https://ai.google.dev/gemini-api/docs/whats-new-gemini-4-carbon),
[structured output](https://ai.google.dev/gemini-api/docs/structured-output),
[thinking](https://ai.google.dev/gemini-api/docs/thinking),
[long decode](https://ai.google.dev/gemini-api/docs/long-decode).

November standard rates are USD2 per million uncached input, USD.10 per million
implicit cached input and USD10 per million output, including thoughts. The
December 1 schedule doubles all three. The estimate includes actual hidden
output and input-cache telemetry. Paid abuse-prevention logging can apply.
Only the six owner-authored synthetic frame packets were authorized.
[Pricing](https://ai.google.dev/gemini-api/docs/pricing#gemini-4-carbon)
and [paid terms](https://ai.google.dev/gemini-api/terms#paid-services).

All source packets were submitted to the respective providers' token-count
endpoints before inference. Full reviewer packets used the prior complete
same-case Sol response for dry-run sizing only. The actual anonymous answer
replaces it and is counted again before each blind Opus request. Three arms
share the fixed source-aware rubric, reference and original image order from
Attempt057. No subject receives a model answer, reference description or score.
No cache or output from the previous run substitutes for current inference.
