## Untriaged

- Agentic video-validation loop: CineForge needs first-class tooling for AI agents to inspect generated video, not just guess from logs or a couple of framegrabs. Frame extraction is a useful baseline, but it misses motion defects like stepped zooms or stutter. We should add a stronger loop that can sample clips over time, inspect audio/video streams, analyze motion continuity, and optionally send finished previz/render outputs to a multimodal model (Gemini/OpenAI/etc.) for semantic validation. Audio needs the same treatment: native agent checks can cover duration, loudness, silence, waveform/spectrogram, clipping, and transcript-level structure, but not real listening-quality judgment, so we likely need model-assisted audio QA too. Not urgent for current previz MVP, but it becomes mandatory once final render/video quality is a core product surface.
- Intent-side visual direction stack: `production_format` should stay a base medium/archetype control (`live action`, `anime`, `graphic novel`, etc.), but the Ideal wants a broader taste stack in Intent. Add a follow-on that layers director/film references, uploaded mood-board imagery, and freeform look notes into a transparent compiled creative brief for downstream image/video generation. Script should only show a breadcrumb back to Intent, not own the editor.
